## 定期检查四类（每第 5 篇 ingest 后建议执行）

> 前三类涉及批量核查时**必须输出覆盖清单**——没有覆盖清单的核查不算完成；**要全量，不抽样**。

### A. 去重合并

- [ ] 按 `topics` 聚类，找语义重复 / 已被取代 / 过度碎片化的条目
- [ ] 合并时旧页标 `retired_at` + `superseded_by`（**不删**）
- [ ] 重建 `_WikiIndex.md` 与受影响页的 §1

### B. 回原始核查（逐段对照 `pass2/` 的 `E` 对象）

- [ ] **漏了关键限定**（如"仅在英文中"被省略）
- [ ] **丢了否定词**（"不推出"写成"推出"）
- [ ] **丢了时间条件**（"2016–2020 美国"被省略）
- [ ] **把推测当事实**（Provisional 解读被写成结论）

### C. 冲突场景限定

- [ ] 矛盾的两条若**各自成立**，是否写明适用条件（时间 / 对象 / 领域 / 任务）
- [ ] 证据不足的是否**保留待确认**（未强行裁定）

### D. 失效下线

- [ ] 过期内容已加 `retired_at`，检索期被过滤
- [ ] 被问起时摘要中标注「此条已废止（失效于 …，由 `Cxx` 取代）」
